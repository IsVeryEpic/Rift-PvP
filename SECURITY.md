# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, leaked credentials, or sensitive server data in a public issue.

Report security concerns privately to the repository owner through GitHub's private contact options. Include the affected version or commit, impact, reproduction steps, and any relevant logs with secrets removed.

## Sensitive data

Never commit API keys, tokens, passwords, private server configuration, player data, backups, or credentials. If a secret is accidentally committed, revoke or rotate it immediately; removing it from a later commit does not invalidate it.
